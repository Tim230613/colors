# Color Mini App - Заметки о проекте

## Описание
Telegram Mini App с игрой на память цвета. Игрок запоминает оттенок и яркость цвета за 3 секунды, затем пытается восстановить цвет с помощью двух бегунков (оттенок и яркость).

## Структура проекта
- `bot.py` - Telegram бот на Python
- `app.js` - JavaScript логика игры
- `index.html` - HTML страница мини-аппа
- `styles.css` - стили
- `requirements.txt` - зависимости Python
- `.env.example` - пример конфигурации

## Как работает
1. Игрок видит случайный цвет на 3 секунды
2. Цвет скрывается
3. Игрок использует два бегунка (оттенок 0-360°, яркость 0-80%) чтобы восстановить цвет
4. Результат показывается в виде градиента (слева правильный, справа игрок)
5. Результат отправляется в бота

## Запуск
### Локальная проверка сайта
```powershell
python -m http.server 8000 --bind 127.0.0.1
```
Открыть: http://127.0.0.1:8000/

### Запуск бота
1. Опубликовать файлы на HTTPS-хостинге
2. В BotFather указать домен мини-аппа
3. Создать `.env` с BOT_TOKEN и WEB_APP_URL
4. Запустить: `python bot.py`
